Twisha Privacy Policy

Last updated: October 3, 2026

Twisha is a Discord application developed and maintained by Soul. This Privacy Policy explains what Discord-related data Twisha may access, how it is used, where it may be processed, and how users can request deletion.

1. Data Twisha May Access

Depending on the features used, Twisha may access:

  • Discord User ID, username, display name and avatar-related information.
  • Server/Guild ID and server configuration information.
  • Channel, role and permission information required for bot functionality.
  • Guild member information required for member-related features.
  • Message content when required to process supported commands.

2. How Message Content Is Used

Twisha uses Message Content only when necessary to identify and execute supported message-based commands, including prefix commands, mention-based commands and authorized no-prefix commands.

If command logging is enabled, relevant message content may also be transmitted to an owner-controlled logging endpoint/webhook for operational logging and debugging. Twisha does not use message content for advertising, user profiling, or machine learning/AI training.

Important: Message content is processed only for stated bot functionality. Users should avoid sending sensitive personal information in messages to or through bot commands.

3. Storage and Databases

Twisha uses PostgreSQL and Redis for operational bot data. Depending on the feature, this may include server configuration, user/server settings, prefixes, playlists, music-related settings, premium or vote information, staff configuration, no-prefix settings, and other feature configuration data.

Message content is not intentionally stored as a permanent application database record merely because it was processed as a command. Where command logging is enabled, content may be transmitted to the configured logging destination and may be retained there according to that destination's configuration.

4. Third-Party Services

Twisha may interact with Discord and third-party services required to provide features such as music playback, hosting, databases, logging, or integrations. Data is shared only when necessary to provide the relevant functionality or when required by law.

5. Data Use Restrictions

Twisha does not:

  • Sell Discord user data.
  • Use Discord data for advertising or user profiling.
  • Use message content to train machine-learning or AI models.
  • Collect Discord passwords or authentication tokens from users.

6. Data Retention and Deletion

Twisha retains operational data only for as long as reasonably necessary for the bot's stated functionality, legal obligations, security, or troubleshooting. When data is no longer necessary, it may be deleted or anonymized.

Users can request deletion of data associated with their Discord account or server by contacting the developer. Requests should include the relevant Discord User ID, Server/Guild ID, or other information necessary to identify the requested data.
